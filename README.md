# Ajit Gupta - Portfolio

A modern, responsive portfolio website showcasing my education, skills, projects, and professional experience.

## 🚀 Built With

- **React** - Frontend framework
- **TypeScript** - Type-safe JavaScript
- **Vite** - Fast build tool and dev server
- **CSS3** - Modern styling with animations and glassmorphism effects

## ✨ Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Modern Aesthetics** - Vibrant gradients, glassmorphism, and smooth animations
- **Smooth Scrolling** - Elegant navigation between sections
- **Interactive Elements** - Hover effects, floating animations, and dynamic components
- **SEO Optimized** - Proper meta tags and semantic HTML

## 📋 Sections

1. **Hero** - Introduction with animated background and stats
2. **Education** - Academic background at BMS College of Engineering
3. **Skills** - Technical skills organized by category
4. **Projects & Hackathons** - Showcase of AI Agent Verse, CV Engine, and hackathon wins
5. **Work Experience** - Professional experience at Hinge Health and SASMOS
6. **Contact** - Get in touch form and social links

## 🛠️ Development

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📱 Local Development

The development server runs at `http://localhost:5173/`

## 🎨 Design Features

- **Color Palette**: Vibrant gradients with purple, pink, and cyan accents
- **Typography**: Inter and Space Grotesk fonts for modern readability
- **Animations**: Fade-in effects, floating elements, and smooth transitions
- **Glassmorphism**: Frosted glass effect on cards and components
